💱 Currency Converter Bot — Telegram бот для конвертации валют

Telegram бот для конвертации валют с акцентом на пары с **белорусским рублём (BYN)** и **российским рублём (RUB)**. Также получает свежие новости о курсах валют из финансовых RSS-лент.

## ✨ Возможности

- 💰 **Конвертация валют** — поддерживает 8+ мировых валют
- 💸 **Специализация на RUB/BYN** — быстрая конвертация российских рублей в белорусские и обратно
- 📊 **Актуальные курсы** — получение курсов в реальном времени через API
- 📰 **Новости валют** — свежие финансовые новости из 4+ источников
- 🔄 **Кэширование** — экономия API запросов (курсы: 1 час, новости: 10 минут)
- 🎨 **Inline-клавиатуры** — удобный выбор валют и управления новостями

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install pyTelegramBotAPI aiohttp python-dotenv feedparser
```

Или через `requirements.txt`:

```bash
pip install -r requirements.txt
```

### 2. Настройка бота

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен
2. Создай файл `.env` в корне проекта:

```env
BOT_TOKEN=твой_токен_от_botfather
```

### 3. Запуск

```bash
python bot.py
```

## 📖 Использование

### Команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и приветствие |
| `/help` | Показать справку |
| `/news` | Получить свежие новости о валютах |

### Конвертация валют

#### Текстовый ввод

Поддерживаются форматы:
- `100 rub in byn` — российские рубли → белорусские
- `50 byn in rub` — белорусские → российские рубли  
- `100 usd in byn` — доллары → белорусские
- `50 eur to byn` — евро → белорусские
- `2000 rub in usd` — любые другие пары

#### Кнопки

1. Нажми **💱 Конвертировать**
2. Выбери валютную пару
3. Введи сумму

### Просмотр курсов

1. Нажми **📊 Курсы валют**
2. Выбери интересующую пару
3. Бот покажет текущий курс и обратный

### Новости

1. Нажми **📰 Новости валют** или используй `/news`
2. Получи 5 последних финансовых новостей
3. Используй кнопки:
   - **🔄 Обновить новости** — принудительное обновление
   - **📰 Больше новостей** — показать 10 новостей

## ⚙️ API и кэширование

### Currency API
- **Источник**: [ExchangeRate-API](https://www.exchangerate-api.com/)
- **Лимит**: 1500 запросов/месяц (бесплатный тариф)
- **Кэширование**: 1 час

### Новости
- **Источник**: RSS-ленты финансовых изданий
- **Кэширование**: 10 минут
- **Обновление**: По требованию или при нажатии "Обновить"

## 🐛 Возможные проблемы и решения

### Проблема: Не загружаются новости
**Решение**: Проверь интернет-соединение. RSS-ленты могут временно быть недоступны.

### Проблема: Ошибка при конвертации
**Решение**: Проверь правильность написания валюты (например, `usd`, а не `usa`).

### Проблема: Бот не отвечает
**Решение**: Убедись, что токен в `.env` корректен и бот не заблокирован.

### Проблема: Ошибка "RuntimeError: This event loop is already running"
**Решение**: Это связано с асинхронностью в telebot. Перезапусти бота — проблема решится.
